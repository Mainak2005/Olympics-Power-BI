🏅 Olympics Data Analysis Dashboard (Power BI)

📌 Overview
This Power BI dashboard provides an interactive analysis of historical Olympic Games data, focusing on athlete demographics, medal distribution, and performance trends across countries, sports, and years.

The goal of this project is to uncover meaningful insights from Olympic data using data visualization and exploratory analysis techniques.

🎯 Objectives
Analyze medal distribution across countries
Identify top-performing athletes
Explore trends in athlete participation over time
Study relationships between physical attributes (height & weight)
Understand demographic patterns such as age distribution

📊 Dashboard Features
🔹 Filters (Slicers)
Sport
Gender (Sex)
Year Range
City
Medal Type
Season
These slicers allow users to dynamically explore the dataset.

📈 Key Visualizations
🥇 Countries by Total Medals
Bar chart showing top countries based on medal count
Highlights dominance of nations like the United States and others
🧑‍🤝‍🧑 Athletes by Total Medals
Displays top athletes with the highest medal counts
Helps identify consistent performers
📅 Total Athletes by Year
Shows participation growth over time
Highlights how the Olympics expanded globally
📊 Sports Participation
Distribution of athletes across different sports
Identifies the most popular Olympic sports
📏 Height vs Weight Correlation
Scatter plot showing relationship between height and weight
Useful for identifying general athletic body trends
🎂 Athletes by Age
Histogram showing age distribution
Most athletes fall within peak performance age ranges
⚖️ Athletes by Weight
Distribution of athlete weights across events
📏 Athletes by Height
Distribution of athlete heights

🔍 Key Insights
Certain countries consistently dominate medal counts
Athlete participation has significantly increased over the years
Most athletes fall within a specific age range (early to mid-20s)
There is a positive correlation between height and weight
A few athletes stand out with exceptionally high medal counts

🛠️ Tools & Technologies
Power BI – Data visualization & dashboard creation
Data Cleaning & Transformation – Power Query
Data Modeling – Relationships & measures using DAX

📂 Dataset
Olympics historical dataset (Athletes, events, medals, etc.)
Includes attributes like age, height, weight, country, sport, and year

🚀 How to Use
Open the Power BI .pbix file
Use slicers to filter data dynamically
Hover over visuals for detailed insights
Explore different combinations for deeper analysis
